# 小红书卡片产出标准 v1.1（note 主题基线）

> 2026-10-11 v1.1 定稿（用户拍板）。每次产出按此执行，出图后过 §6 QC 清单。
> 改标准 = 改 `md2card.py` / `note-style.html` 常量重渲。

## 1. 字体体系（字号一律 4 的倍数）

| 角色 | 字号 | 行高 | 字重 | 硬规则 |
|---|---|---|---|---|
| 封面/结尾 H1 | 72px | 1.3 | 800 | **蓝色** #2f5cff，≤2 行 |
| 内容页 H2 | 56px | 1.3 | 800 | **蓝色**，**单行 4–6 字**，每页 1 个 |
| 正文 | 32px | 1.6 | 400 | **纯黑 #2b2b2b**，单页 ≤12 行 |
| 表格 | 28px | 1.5 | — | 行数 ≤7，超了拆页 |
| 卡片标题 .ct | 28px | — | 700 | |
| 标签 .tag | 24px | — | 600 | |
| 页脚/页码 | 20px | — | 500 | 每页统一 |

- **字体：黑体（无衬线）**——PingFang SC / Microsoft YaHei UI，不用宋体/衬线（用户明确否掉花哨衬线）
- **最小字号 20px**
- 强调：`**xx**` 黄马克笔 w600；蓝色加粗 w700

## 2. 排版间距

- 页面 1080×1440；页边距 上76 / 左右84 / 下60
- **内容饱满，行距略微紧凑**（正文 1.6），段间距正常（28–36px）
- 内容覆盖 ≥80% 画布高；中部纯空白带 **≤250px**（出图后目测，超了补内容而不是拉大间距）
- 一张卡只讲一个主题

## 3. 特色效果配额

| 效果 | 每页上限 |
|---|---|
| 黄马克笔高亮 | ≤3 处 |
| 蓝色强调 | ≤2 处 |
| 蓝卡 / 黄卡 | 各 ≤1 个 |
| emoji | 标题/表格行首可用，正文 ≤2 个 |
| 表格 | ≤1 个/页 |
| 步骤条 | ≤5 步/页 |

**原则：特效宁少勿多**（用户原话）。图标体系（卡通/矢量小图标）后续迭代进 skill，先用 emoji + ✦ 项目符号。

## 4. 内容规则（选题与标题）

- **标题通俗化**：用「PRD」「面试」「大厂」「秋招」这类热词，目标读者要有"不劳而获的快感"——看完就觉得能直接用。学术/抽象标题（如「策略匹配机制初探」）一律改写成场景化表达
- 标题公式备选：`XX 是什么（人话版）` / `面试被问 XX 怎么答` / `大厂 XX 的底层逻辑` / `一张图看懂 XX`
- 正文多给"能直接抄的"：公式、清单、句式模板，少给论述
- **篇幅分档**：短档 3–6 张（单点速览），长档 10–15 张（系统干货）；**前期以长档为主**，做系列感
- 收尾页必须有：万能公式/清单 + 收藏引导

## 5. 固定结构

- 顶部：品牌标签（左）+ 页码（右）；底部：虚线 + 系列名 + 引导语
- 封面：H1 钩子 + 一句话定义卡 + 「这一篇你会拿到」清单
- 内容页：H2（4–6字）+ 正文/表格/步骤 + 至多一卡收束

## 6. QC 清单（每次出图逐项过）

1. ☐ H2 全部单行 4–6 字
2. ☐ 无文字溢出/截断
3. ☐ 中部无 >250px 空白带
4. ☐ 高亮 ≤3 处
5. ☐ 无 <20px 文字
6. ☐ 缩略图测试：缩到 360px 宽标题可读
7. ☐ 页码/页脚/标签齐全一致
8. ☐ 标题够通俗吗（姐妹视角：刷到会不会点）
