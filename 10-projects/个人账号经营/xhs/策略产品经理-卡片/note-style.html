策略产品经理 · 入门01 / 08 · 关注看全系列
定义02 / 08

一个策略，六个要素

在业务里，策略 = 针对特定对象、在特定场景下，按规则行动，再用结果持续优化。

要素以京东优惠券为例
🎯 目标提高购买转化率，控制优惠成本
👤 对象新用户 / 高价值用户 / 价格敏感用户
⏰ 场景加购未结算、大促活动期间
🎬 行动向用户发放优惠券或权益
⚙️ 规则按特征决定 给谁发、发什么券、发多少
📊 评估领取率、使用率、转化率、ROI

这套「如何判断 + 如何行动」的规则，就是一个策略。

角色对比03 / 08

两种 PM，两个问题

功能型产品经理

设计「用户怎么用」

关注交互、流程、页面：下单路径怎么走、按钮放哪。

策略型产品经理

设计「系统怎么决策」

关注规则、特征、数据：什么用户在什么场景拿到什么券、内容排第几位。

常见策略方向：

  • 搜索策略 · 推荐策略（头条个性化推荐）
  • 广告策略 · 风控策略
  • 用户增长策略 · 补贴策略（滴滴订单分发）

大型产品，一定不能缺少策略产品经理。

日常工作04 / 08

策略 PM 的四步日常

1
需求调研 🔍
哪些用户没买？为什么？券能不能解决？——访谈 + 业务反馈 + 数据分析
↓
2
产品规划 📝
定清楚什么用户、什么场景、发什么券、发多少 → 写成 PRD
↓
3
项目落地 🛠
和算法、研发、数据协作：特征计算、发券规则、策略配置后台
↓
4
迭代优化 🔄
盯领取率、使用率、转化率、成本；不行就调分层和力度

记忆公式：调研 → 规划 → 落地 → 迭代，和所有 PM 一样，只是对象从「页面」变成了「规则」。

匹配原料05 / 08

发券之前，先看三类特征

👤 用户特征

用户类型 · 品类偏好 · 历史购买 · 浏览加购 · 优惠敏感度 · 活跃程度

→ 他是谁？对优惠有多敏感？

🎫 优惠券特征

适用品类 · 优惠类型 · 额度 · 使用门槛 · 有效期 · 发放成本

→ 这张券适合谁？成本多少？

🌏 环境特征

时间 · 地理位置 · 天气 · 设备渠道 · 促销活动

→ 他现在处在什么消费场景？

特征是策略的地基：系统先「认识」用户和券，才能谈匹配。

策略产品经理 · 入门05 / 08
决策闭环06 / 08

一套策略的决策闭环

步骤核心问题
① 识别用户这个用户是谁？有什么需求？
② 判断场景现在存在购买机会吗？
③ 匹配优惠什么券最适合他？
④ 策略决策给不给？什么时候给？给多少？
⑤ 效果评估这次策略真的有效吗？
⑥ 策略优化下一次怎么做得更好？
💡 增量思维（最容易忽略）

不是让「本来就会买的人」拿到优惠，而是找到「被优惠刺激才会买」的用户，用合理成本换增量转化。

实战案例07 / 08

同一个系统，两种决策

👤 用户 A · 美妆加购少女

连续浏览美妆商品 🛍 购物车有件 ¥120 的商品 · 历史常用优惠券

系统判断：美妆兴趣 + 优惠敏感 + 强购买意愿

→ 动作：发美妆 「满 100 减 20」 🎫

👤 用户 B · 外卖新用户

刚用京东外卖 🧋 下单集中在饮品店 · 消费频次还很低

系统判断：新客习惯培养期 + 品类兴趣明确

→ 动作：饮品品类定向激励，不发通用券

真实业务还会叠加机器学习打分、预测模型、A/B 实验、用户分层——但底层逻辑不变。

面试官问「系统怎么决定给谁发券」，按 特征 → 场景 → 匹配 → 决策 四步答。

总结08 / 08

策略，就是让系统
学会因人而异地决策

策略 PM 做的事：把「如何决策」变成可执行的规则，并用数据持续验证。

🧭 万能公式

明确目标 → 识别用户 → 判断场景 → 制定规则 → 数据验证 → 持续优化

⭐ 面试考点

产品设计「用户怎么用」，策略设计「系统怎么判断」。
